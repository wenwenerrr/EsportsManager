# Game Brief: 战队经理人（暂名）

**One-sentence pitch:** 经营一支电竞战队，每个赛段在训练、运营和选手状态之间做取舍。冠军、流量还是生意，成功由你来定义。

> **数值与公式**：所有数值公式、权重、性格效果和相性见 `design/numbers.md`。性格为十组对立的性格词，每名选手抽两个不同组的词。

## Core loop
- **看状态**：赛段开始，查看战队三角（实力 / 人气 / 经济）和每个选手的心情、压力，以及队伍默契
- **排行动**：给战队和选手安排训练、直播、商务、休息等行动，每种行动都会推动三角的一边，同时影响选手状态
- **打比赛**：选首发和战术倾向，按数值模拟 BO 系列赛，带随机性；输出战报，说明输赢原因
- **结算**：三角和选手状态变化，触发性格驱动的事件，然后进入下一个赛段。一年 12 个赛段，第 3、6 赛段后打春季赛、夏季赛，年末打年度总决赛，两年之间是转会期（见 `design/numbers.md` §4.18）

## Player goal & fail state — what "working" looks like
- **目标**：自由选择。每年的年终总结按四条路线分别评价：竞技（赛季排名）、商业（资金和赞助）、人气（粉丝数）、成长（选手能力提升）。没有哪一条是"正确答案"
- **失败**：资金归零，战队破产
- **一局完整的体验**：打完一整年，看到年终总结

## MVP — what must exist to be the game
- **虚构选手池和选手属性**：选手用**电竞 ID** 作为名字（不用姓名）；分路能力雷达（六维，见下表）、颜值、人气、分路、心情、压力、性格、薪资、年龄。打非主分路时按目标分路的六维评估并打折扣

  | 分路 | 六维 |
  |---|---|
  | 对抗路 | 每死承伤 / 伤害占比 / 开团能力 / 参团率 / KDA / 指挥能力 |
  | 打野 | 分均经济 / 经济转化 / 参团率 / KDA / 击杀贡献 / 指挥能力 |
  | 中路 | 伤害占比 / 参团率 / 经济转化 / KDA / 控制时长 / 指挥能力 |
  | 发育路 | 发育能力 / 经济转伤害 / KDA / 参团率 / 生存能力 / 指挥能力 |
  | 游走 | 参团率 / 每死承伤 / 控制时长 / 开团能力 / 治疗量 / 指挥能力 |
- **战队三角加默契**：实力 / 人气 / 经济三项数值互相牵制，默契受人员变动和性格搭配影响
- **赛段行动分配**：训练、直播、商务、休息，以及它们对三角和选手状态的影响
- **比赛模拟**：首发和战术选择，BO 数值模拟（胜率有封顶），赛后战报
- **年度循环和转会期**：春季赛、夏季赛、年度总决赛，加一个转会期。转会期三选一：
  - **拍卖**：竞拍青训或成熟选手。成交金额流入卖方俱乐部，会增强对手；不出手，强援可能被对手买走
  - **全国选拔**：费用低、消耗本次转会期、结果随机；本队越缺人的位置越容易选到好苗子（天赋概率很低）
  - **出售**现有选手（选手互换的交易以后再做，见 `design/gdd/transfer.md`）
  - **对手俱乐部**与玩家用同一套规则经营（训练、赚钱、买卖、换风格），见 `design/gdd/league.md`
- **意外事件**：主要挂在行动上，每个行动点都有概率触发好事或坏事，改变这次行动的结果（类似《中国式家长》）；另有少量由性格、状态和选手关系触发的事件。事件是梗的主要载体（数值见 `design/numbers.md` §4.17）
- **破产判定和年终总结**：多路线评价

## Out of scope — not building this
- 历史模式，以及任何真实战队或选手的映射
- 实时操作比赛、英雄 BP、对局画面
- 联网和多人
- 教练、分析师等工作人员系统
- 精致的美术和动画（第一版用文字、色块和简单卡片）

## Build order
1. **三角加行动分配**（纯文字界面）：先验证取舍有没有张力，比如只训练会不会破产、只搞运营会不会掉粉
2. **比赛模拟和战报**：让实力真正有意义
3. **选手状态联动**：心情、压力、默契接入行动和比赛
4. **意外事件**（2026-10-19 提前：第一次试玩后觉得只经营数值太单调）
5. **年度循环和转会期**
6. **年终总结**

---
**Who it's for / what they feel:** 喜欢经营模拟的玩家，KPL 观众会额外读懂梗。核心感受是带着一群性格各异的年轻人往上走，用自己的方式获得成功。

**Art & audio direction:** 简洁的 2D 界面加选手卡片（第一版用文字和色块代替立绘），轻快的 UI 音效。选手头像由程序生成（脸型、发型、配色等部件随机组合，颜值影响结果），不画立绘。

**Reference game:** 《皇帝成长计划》。保留按时间段分配行动、属性互相联动、多种结局的结构；不要它的大量剧情文本和单一的成长主线。
