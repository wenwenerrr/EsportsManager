## Summary

比赛系统决定两支俱乐部打一个系列赛时每一局谁赢、为什么赢。一局分前期、中期、后期三个阶段，胜负主要由双方**养成出来的阵容**决定；三个阶段**互相克制**（前期克后期、团战克前期、后期克团战），所以最好的阵容取决于对手和整个联赛在练什么。赛前选的战术是轻量的"对阵匹配"，最多值 3 分；选手的心情和压力对比赛只有中等影响（最多约 −7%）。

> **Quick reference** — Layer: `Core` · Priority: `MVP` · Key deps: `player-model, team-state, season-calendar`

## Overview

比赛是电竞战队经理人里**唯一把阵容强弱变成名次和奖金的地方**。玩家和 7 支 AI 俱乐部规则完全相同：选五名首发和一个战术（入侵 / 团战 / 发育），系统按 BO1～BO9 逐局模拟。

- **输入**：双方首发（六维、心情、压力、是否打主分路、性格）、双方默契、双方战术、绝活挂钩值
- **输出**：每局胜负、系列赛比分、战报分项（三个阶段、明星、克制循环、战术匹配、克制、运气）、"换个战术会怎样"和"没有绝活会怎样"的对照
- **核心思路**：
  - 每队在前期、中期、后期各有一个实力
  - **三阶段克制循环**：一方在 X 阶段实力领先（不含明星项）、另一方在被 X 克制的阶段领先时，后者的优势打折（前期克后期 = 比赛提前结束；团战克前期 = 一波团战抹平前期劣势；后期克团战 = 拖到后期、避开团战）
  - 前期和后期奖励**明星**（一路明显超出全队水平）；中期看**短板**（团战看最弱的人）
  - 战术：专注自己领先的阶段有小幅加成，克制关系再给一点点（合计最多 3 分）
- **深度放在哪里**（用户决定 2026-10-22 / 10-23）：长期养成——练哪个阶段、走什么风格、培养谁当明星；并且要看联赛里别人在练什么
- **取代**：`numbers.md` §4.9 的单一战力 P 和 §4.14 的对手 `form`。赛历、赛制、奖金（§4.18）不变

## Player Fantasy

**我养出来的队伍有自己的样子，而且我知道它克谁、怕谁。**

- 赛前：看对手阵容的雷达图形状和最近的打法，知道"它前期强，我们后期强，它能把比赛提前结束；但我们团战也不差"，选一个合适的战术
- 赛季之间：看积分榜上各队的风格。两支强队都在练前期，那练团战就有优势；你靠后期夺冠后，对手转练前期来针对你
- 赛后：战报说清"我们前期被打穿，比赛提前结束，后期优势没兑现"，或者"换团战本可多 2%"，或者"这一局是运气"
- 弱队有办法：在被克制的对手面前，阵容总实力略低也能赢
- 感受锚点：第二年你用后期阵容夺冠，两个对手改练前期；你的发育路要求加薪——是给他加，还是卖掉他转练团战？

参考：《中国式家长》《女寝皆是修罗场》里取舍来自长期投入的机会成本，没有一眼就对的答案。

## Detailed Design

### Core Rules

**设计决定记录**
- 2026-10-22（初稿）：战术保持 3 种；单局胜率 15%～85%；不显示"被对手研究"
- 2026-10-22（第一次评审后，用户）：深度放在长期养成；战术为轻量对阵匹配，己方战术选择对 G 的影响最多 3 分；对手信息 = 人员 + 雷达图形状（无数字）+ 最近战术；不做比赛小游戏；系列赛内不换战术；绝活只改本队
- 2026-10-23（完整评审后，用户，见 `design/match-model-v4.md` §17）：
  - **D1**：心情和压力主要影响养成；对比赛的影响降到中等（最多约 −10%）
  - **D2**：三阶段石头剪刀布（前期克后期、团战克前期、后期克团战），**温和**强度；团战看短板，前期和后期奖励明星；去掉隐藏情报度（在联赛系统）
- 同日由评审直接修正（不需用户决定）：提前结束改为连续（固定分母）；绝活不再带战术条件（否则突破 3 分预算）；默契对团战改为相对值；明星项扣除随机门槛并封顶；分阶段的短板惩罚；战术节奏双方相同（见下）
- 2026-10-27（全系统原型 fixG 回写，用户确认）：克制强度 `s` 0.35 → 0.22；克制系数改用**不含明星项**的阶段实力差 `ΔS_X`（含明星项时前期 / 后期对其他阶段的压制系统性偏强）；`κ_s` 0.05 → 0.025（状态对比赛最多约 −7%）；BV1 目标改为 0.51～0.55。标 * 的数值待任务 014 重测

**参赛条件**
1. 五个分路各有一名首发；同一名选手不能在同一队首发两次，也不能同时为双方首发。否则**拒绝比赛**：报错（`InvalidLineup`，含分路 id 或选手 id），不抽随机数，不改变任何状态。
2. `bestOf` 必须是 1～9 的奇数（赛历用 3 / 5 / 7）。否则报错，不抽随机数。
3. 比赛是**纯函数**：输入两个阵容快照、双方战术、双方挂钩表、配置和随机源，输出结果；不修改任何对象。
4. A 方 = 调用时第一个阵容，B 方 = 第二个。规则对两方完全对称：交换 A、B 后（含各自的挂钩表），无波动时 `p_A + p_B = 1`。

**战术节奏**（与 `numbers.md` §4.18 一致，双方相同）：常规赛整段用一个战术；季后赛开始前可以换一次；年度总决赛开始前（半决赛前）选一次，决赛沿用。玩家和 AI 都按这个节奏；比赛系统只接收每场的战术。

**求值顺序**（每局都按此顺序；只有第 11 步起的随机部分每局不同，决胜局改第 2 步）

1. 每名首发的每个维度算**有效值** `v'`（F1）
2. 若本局是决胜局，各方所有 `v'` 乘本方决胜局系数（F14）
3. 每名首发的**阶段评分** `r(i,k)`（F2）
4. 队伍**阶段实力** `S_k`：分路加权平均减**本阶段的**短板惩罚（F3）
5. **中期默契**：`S_M` 加上本队默契带来的加减值（F4）
6. **绝活加值**：本队 `phase_flat[k]` 加到 `S_k`（挂钩表）
7. **指挥分与执行力**（F5）
8. **阶段差** `Δ_k = S_A,k − S_B,k`；前期和后期再加明星项（F6）
9. **克制循环系数** `f_k`（用不含明星项的阶段实力差 `ΔS_X`）和**基础分**（F7、F8）
10. **战术匹配项**和**克制项**（F9、F10）
11. **波动**：抽 `ε_A`、`ε_B`（F11）
12. **单局差值** `G` 和**胜率** `p`（F12、F13）；抽掷骰数 `u`，`u < p` 则 A 方赢

**阶段与维度**（配置 `match_config.json`；用配置 id 书写）

| 分路 | 前期 E | 中期 M | 后期 L |
|---|---|---|---|
| top | kda | damage_taken_per_death, engage, teamfight_participation | damage_share |
| jungle | gold_per_min, kda, kill_contribution | teamfight_participation | gold_conversion |
| mid | kda | teamfight_participation, cc_duration | damage_share, gold_conversion |
| adc | kda | teamfight_participation | farming, gold_to_damage, survival |
| support | teamfight_participation | damage_taken_per_death, cc_duration, engage | healing |

- `command`（指挥能力）不属于任何阶段
- 配置校验：每个分路每个阶段至少一个维度；每个维度至多属于一个阶段；所有非指挥维度都有归属；指挥不得出现在映射里
- 注意：前期有 4 个分路只有一个维度，训练这一维就等于练整个前期。各阶段训练成本是否对等由成长系统处理（growth.md）

**队伍阶段实力**
- 五人阶段评分按分路权重 `Lw[k][分路]` 加权平均，再减去该阶段的短板惩罚。**惩罚强度分阶段**：前期 0.15、中期 0.5、后期 0.15——团战看最弱的人，对线和后期看明星
- 分路权重：前期 打野 1.5、中路 1.2、其余 1；中期 游走 1.3、对抗路 1.2、其余 1；后期 发育路 1.6、中路 1.2、其余 1
- 中期默契：默契比 50 高或低，中期实力相应加减（每 10 点默契 ±1 分，最多 ±5）。双方默契相同时互相抵消

**明星项（前期和后期）**
- 比较每条路的阶段评分差。明星项 = 最大一路领先 − 全队平均领先（平均为负时按 0）− 门槛 4 分，结果在 0～15 之间
- 门槛去掉随机波动带来的"假明星"；上限防止一个维度堆到极端（"明星堆砌"）
- 中期没有明星项

**三阶段克制循环**（D2）
- 三条克制关系：**前期 → 后期**、**团战 → 前期**、**后期 → 团战**
- 规则：对每条"X 克 Y"，如果 X 阶段**实力**的领先方（`ΔS_X = S_A,X − S_B,X`，**不含明星项**）和 Y 阶段的领先方（`Δ_Y`，含明星项）不同，Y 阶段的领先方在 Y 上的优势打折：`f_Y = max(w_min, 1 − s × |ΔS_X| / 10)`；否则 `f_Y = 1`
- 每个阶段只被一条关系影响（前期被团战影响、后期被前期影响、团战被后期影响）
- 强度**温和**（`s` 0.22，`w_min` 0.4）：风格偏向 9 分的队对被克制的队单局约 52%*，偏向 12 分时约 54%*；专精队对均衡队约 50%（* s 0.22 的数值为估计，任务 014 重测）
- 基础分用**固定分母**的加权平均，所以分数连续：一方阶段领先从负变正时，分数不会跳

**战术**
- 3 种：入侵（专注前期）、团战（专注中期）、发育（专注后期）
- **战术匹配**：专注的阶段本队领先有加成，落后有惩罚，幅度随执行力，**每方 ±1 分**
- **克制**：入侵克发育、发育克团战、团战克入侵；克制方 `+0.5 × 执行力`
- **战术预算**：对固定的敌方战术，己方三种战术之间 `G` 最多相差 3 分（2F + 2C）。配置校验这一点
- 只有当本队两个领先阶段的差距在 5～10 分以内，对手的战术才会影响你的最优选择（C/a 比值决定）

**单局胜负**
- `G` = 基础分 + 双方战术匹配之差 + 克制项 + 双方波动之差
- `p` = logistic(`G/k`)，钳制在 [p_floor, 1 − p_floor] = [0.15, 0.85]
- 每局固定抽 3 个随机数：A 方波动、B 方波动、掷骰（不论波动是否为 0）

**系列赛**：先拿到 `bestOf/2+1` 局者胜。决胜局 = 双方都差一局获胜的那一局（BO1 的唯一一局也是）。

**绝活挂钩点**（只改本队，无条件，按求值顺序生效）

绝活的获得、失去、列表和效果数值由成长系统定义；**过滤（只算首发、只算主分路、同名绝活不重复）也由成长系统完成**，比赛系统只接收汇总后的挂钩表并做合计钳制。

| 挂钩点 | 第几步 | 作用 | 合计钳制 |
|---|---|---|---|
| `phase_flat[k]` | 6 | 本队 `S_k` 加减 | 每阶段 [−5, +5] |
| `star_scale[k]`，k ∈ {E, L} | 8 | 本队明星项乘数 | 乘积 [0.5, 2] |
| `exec_add` | 7 | 本队执行力加减 | 结果钳制 [0.3, 1.0] |
| `sigma_scale` | 11 | 本队波动乘数 | 乘积 [0.7, 1.3] |

- 多个不同绝活作用于同一挂钩点：加减相加、乘数相乘，再钳制
- 挂钩不能带战术条件（2026-10-23：带条件的绝活会让战术差距超出 3 分预算）
- 配置校验：`η × star_scale_max / 5 < min_l(Lw[k][l]/ΣLw[k]) × (1 − λ_k)`，保证提升任何一路都不会降低本队阶段差（单调性）

**战报数据**
- 每局记录：三个阶段贡献 `B_k × f_k × Δ_k / ΣB`（其中明星部分单列）、三个克制系数 `f_k`、`Fit_A`、`−Fit_B`、克制项、`ε_A`、`−ε_B`、无波动 `G₀` 和 `p₀`、实际 `p`、掷骰
- **战术对照**：每局在敌方战术不变时重算 A 方三种战术的 `G₀`（从第 9 步起重算）
- **绝活对照**：每局重算"本队挂钩全为中性"的 `G₀`，差值作为"绝活"分项
- **原因挑选**（系列赛汇总，A、B 各自的视角）：
  1. 分项（共 8 个，各自独立）：前期、中期、后期、明星（E+L 合计）、克制循环（三个阶段因 `f_k < 1` 损失的贡献之和）、战术（`Fit_A − Fit_B` + 克制项）、绝活、运气（波动之和）
  2. 各局相加；对胜方有利、绝对值 ≥ `min_contribution`（0.5）的分项按绝对值排序，取前 `max_reasons`（3）个；不足 `min_reasons`（2）个时补上绝对值最大的其余分项
  3. **运气**：某局输家在该局"自己的"无波动胜率（A 为 `p₀`，B 为 `1 − p₀`）≥ 0.6 时，运气排第一并占一个名额
  4. **势均力敌**：各局 `p₀` 平均落在 0.5 ± 0.05
  5. **提前结束 / 被克制**：任一局某个 `f_k < 1`
  6. **战术建议**：当实际战术的 `G₀` 比最好战术低 ≥ 0.5 分时显示"换成 X 本可 +Y"
- 战报文字由界面生成；每个原因必须对应一个分项

### States and Transitions

两层接口：**纯函数**（测试主要针对它）和外层的**系列赛流程**：

| 状态 | 进入条件 | 退出条件 | 行为 |
|---|---|---|---|
| 待定 Pending | 赛历排出系列赛 | 双方阵容锁定 | 选首发和战术 |
| 锁定 Locked | 阵容通过合法性检查，生成快照 | 开始模拟 | 快照之后改名单、状态都不影响本场 |
| 进行 Playing | 开始模拟 | 一方拿到 `bestOf/2+1` 局 | 逐局计算，每局抽 3 个随机数 |
| 完成 Complete | 决出胜者 | — | 输出结果和战报数据 |

非法阵容在 Pending → Locked 时拒绝，状态保持 Pending。

## Formulas

所有初值都是调参旋钮（`match_config.json`）。2026-10-27 按全系统原型（`tools/sim/`，fixG）回写：`s` 0.22、`κ_s` 0.025、克制系数不含明星项；完整示例的数字已按新值重算；标 * 的数值待任务 014 重测。

### F1 有效维度值

`v' = max(0, v × mood_f × stress_f × lane_f)`

| 变量 | 类型 | 范围 | 来源 | 说明 |
|---|---|---|---|---|
| v | float | 0–100 | player-model | 所打分路的维度值 |
| mood_f | float | 0.95–1.00 | 计算 | `m0 + (1 − m0) × 心情/100`，`m0` 0.95（D1；原 0.7） |
| stress_f | float | 0.975–1.00 | 计算 | `1 − κ_s × 压力/100 × res`，`κ_s` 0.025（2026-10-27；rev 3 为 0.05，原 0.2） |
| res | float | 0.95 / 1 | 性格 | 坚毅 0.95，其他 1 |
| lane_f | float | 0.80–1.00 | 配置 | 主分路 1；非主分路 0.8；非主分路且聪明 0.824 |

**输出范围**：0–100；状态最差时 ×0.92625（约 −7.4%），再加非主分路最低 `0.741v`。
**示例**：v=70，心情 80，压力 40，无坚毅，主分路 → 70 × 0.99 × 0.99 = **68.607**；有坚毅 → 70 × 0.99 × 0.9905 = **68.642**

### F2 阶段评分

`r(i,k) = mean(v'_d for d in Dims[分路(i)][k])`

| 变量 | 类型 | 范围 | 来源 | 说明 |
|---|---|---|---|---|
| Dims | 维度列表 | ≥ 1 | 配置 | 映射表 |
| v'_d | float | 0–100 | F1 | |

**输出范围**：0–100（决胜局最高 103）。**示例**：jungle 前期 {60, 70, 80} → 70；改 command 不影响 r。

### F3 队伍阶段实力

`WS_k = Σ_l Lw[k][l] × r(l,k) / Σ_l Lw[k][l]`，`S_k = WS_k − λ_k × (WS_k − min_l r(l,k))`

| 变量 | 类型 | 范围 | 来源 | 说明 |
|---|---|---|---|---|
| Lw | float | 0.5–2.5 | 配置 | 分路权重 |
| λ_E / λ_M / λ_L | float | 0–0.5 | 配置 | 0.15 / 0.5 / 0.15 |

**输出范围**：`(1−λ)WS + λ·min`，0–103。
**示例**：前期 66 / 70 / 66 / 64 / 66（top / jungle / mid / adc / support）→ WS 66.702 → S_E = 66.702 − 0.15 × 2.702 = **66.296**

### F4 中期默契（相对值）

`S_M ← S_M + χ × (chem − 50) / 10`，`χ` 1.0

| 变量 | 范围 | 来源 |
|---|---|---|
| chem | 0–100 | team-state |
| χ | 0–2 | 配置 |

**输出范围**：−5 到 +5。双方默契相同时对 `Δ_M` 无影响。**示例**：默契 70 → +2；默契 0 → −5。

### F5 指挥分与执行力

`cmd = min(100, max_i(v'_cmd,i × asr_i))`，`exec = clamp(e0 + e1 × chem/100 + e2 × cmd/100 + exec_add, 0.3, 1.0)`

| 变量 | 类型 | 范围 | 来源 | 说明 |
|---|---|---|---|---|
| v'_cmd,i | float | 0–100 | F1 | 有效指挥值（不受决胜局系数影响） |
| asr_i | float | 1 / 1.05 | 性格 | 强势；先乘再取最大 |
| e0/e1/e2 | float | 和为 1 | 配置 | 0.3 / 0.4 / 0.3 |
| exec_add | float | — | 挂钩 | 默认 0 |

**输出范围**：0.3–1.0。**示例**：默契 70、指挥 70 → **0.79**

### F6 阶段差（含明星项）

`lead_l = r_A(l,k) − r_B(l,k)`，`m = mean_l(lead_l)`
`star_A,k = min(cap, max(0, max_l(lead_l) − max(0, m) − st0) × star_scale_A,k)`，B 方以 `−lead` 同理（先乘绝活倍数，再封顶）
`Δ_k = S_A,k − S_B,k + η × (star_A,k − star_B,k)`（k ∈ {E, L}）；`Δ_M = S_A,M − S_B,M`

| 变量 | 类型 | 范围 | 来源 | 说明 |
|---|---|---|---|---|
| η | float | 0–0.4 | 配置 | 0.3 |
| st0 | float | 0–8 | 配置 | 明星门槛 4 |
| cap | float | 5–25 | 配置 | 明星上限 15 |
| star_scale | float | 0.5–2 | 挂钩 | 默认 1 |

**示例**：领先 8 / 10 / 8 / 8 / 8 → 10 − 8.4 − 4 < 0 → 0；一路 +20 其余 0 → 20 − 4 − 4 = **12**；一路 +30 → 30 − 6 − 4 = 20 → 封顶 **15**。

### F7 克制循环系数

对三条关系 (X → Y) ∈ {(E → L), (M → E), (L → M)}：
`ΔS_X = S_A,X − S_B,X`（X 阶段实力差，含默契和 `phase_flat`，**不含明星项**）；`f_Y = max(w_min, 1 − s × |ΔS_X| / 10)`，仅当 `ΔS_X × Δ_Y < 0`（`Δ_Y` 含明星项）；否则 `f_Y = 1`

| 变量 | 类型 | 范围 | 来源 | 说明 |
|---|---|---|---|---|
| ΔS_X | float | — | F3–F4、挂钩 | X 阶段实力差，不含明星项（2026-10-27） |
| s | float | 0–0.9 | 配置 | 0.22（温和；2026-10-27，rev 3 为 0.35） |
| w_min | float | 0.1–1 | 配置 | 0.4 |

**输出范围**：0.4–1。|ΔS_X| ≥ 27.3 时触底。
**示例**（双方明星项都为 0，ΔS = Δ）：Δ_E +8.447、Δ_M −1.673、Δ_L −13.260：前期→后期异号 → f_L = 1 − 0.22 × 0.8447 = **0.8142**；团战→前期异号 → f_E = 1 − 0.22 × 0.1673 = **0.9632**；后期→团战同号 → f_M = 1
**明星项不参与**：A 的前期评分 打野 90、其余四路 60，B 五路 66（中期、后期同完整示例）→ ΔS_E 0.711、Δ_E 4.611（含明星项）、Δ_L −13.260 → f_L = 1 − 0.22 × 0.0711 = **0.9844**（若用含明星项的 Δ_E 会得 0.8986）

### F8 基础分（固定分母）

`Base = Σ_k B_k × f_k × Δ_k / Σ_k B_k`

| 变量 | 类型 | 范围 | 来源 | 说明 |
|---|---|---|---|---|
| B_E / B_M / B_L | float | 0.5–2 | 配置 | 1 / 1.1 / 1（团战 1.1 抵消它没有明星项；"版本更新"也改这三个数） |

**输出范围**：|Base| ≤ max|Δ_k|。连续：任何 Δ 过零时 Base 不跳。
**示例**：(0.9632 × 8.447 + 1.1 × (−1.673) + 0.8142 × (−13.260)) / 3.1 = **−1.452**

### F9 战术匹配项

`Fit_A = clamp(a × exec_A × Δ_focus(t_A), −F, F)`，`Fit_B = clamp(a × exec_B × (−Δ_focus(t_B)), −F, F)`；focus：入侵 E，团战 M，发育 L

| 变量 | 类型 | 范围 | 来源 | 说明 |
|---|---|---|---|---|
| a | float | 0.05–0.2 | 配置 | 0.1 |
| F | float | 0.5–1.5 | 配置 | 1.0 |

**示例**：A 入侵 0.1 × 0.79 × 8.447 = **0.667**；B 发育 0.1 × 0.79 × 13.260 = 1.048 → **1.0**

### F10 克制项

`Counter = C × exec_A（A 克制 B）− C × exec_B（B 克制 A）`，否则 0

| 变量 | 类型 | 范围 | 来源 | 说明 |
|---|---|---|---|---|
| C | float | 0–1 | 配置 | 0.5 |

**战术预算**：配置校验 `2F + 2C ≤ match_tactic_budget`（3.0）。注意：3 分对应的胜率随 `k` 变化（k 8 时约 9%）。
**示例**：A 入侵、B 发育，exec 0.79 → **+0.395**

### F11 波动

`σ_X = (g0 + g1 × avgStress_X/100 × avgRes_X) × (1 − c_cmd × cmd_X/100) × sigma_scale_X`，`ε_X = σ_X × (2u − 1)`

| 变量 | 类型 | 范围 | 来源 | 说明 |
|---|---|---|---|---|
| g0 / g1 | float | 0–5 / 0–10 | 配置 | 2 / 6 |
| avgStress | float | 0–100 | 选手 | 首发平均压力 |
| avgRes | float | 0.95–1 | 性格 | 首发坚毅系数平均 |
| c_cmd | float | 0–0.5 | 配置 | 0.3 |
| sigma_scale | float | 0.7–1.3 | 挂钩 | 默认 1 |

**输出范围**：σ 约 0.98–10.4；`ε ∈ [−σ, σ)`。**示例**：压力 40、无坚毅、cmd 70 → (2 + 2.4) × 0.79 = **3.476**

### F12 单局差值

`G = Base + Fit_A − Fit_B + Counter + ε_A − ε_B`；`G₀ = Base + Fit_A − Fit_B + Counter`

| 变量 | 来源 |
|---|---|
| Base | F8 |
| Fit_A, Fit_B | F9 |
| Counter | F10 |
| ε_A, ε_B | F11 |

**示例**：A 入侵、B 发育：−1.452 + 0.667 − 1.0 + 0.395 = **−1.389**

### F13 单局胜率

`p = clamp(1 / (1 + e^(−G/k)), p_floor, 1 − p_floor)`

| 变量 | 类型 | 范围 | 来源 | 说明 |
|---|---|---|---|---|
| k | float | 4–16 | 配置 | 8 |
| p_floor | float | 0.05–0.25 | 配置 | 0.15 |

**输出范围**：0.15–0.85；|G| ≥ 13.9 时触顶。**示例**：G 0 → 0.5；8 → 0.7311；−1.389（完整示例）→ **0.4567**；−0.979 → 0.4694；±1e6 → 0.85 / 0.15。触顶时 BO3 / BO5 / BO7 = 93.9% / 97.3% / 98.8%。

### F14 决胜局

`dec = mean_i(dec_i)`（果断 1.03，犹豫 0.97，其他 1）；决胜局中该方所有 `v'`（指挥除外）乘 `dec`，从第 3 步重算

| 变量 | 范围 | 来源 |
|---|---|---|
| dec_i | 0.97 / 1 / 1.03 | 性格 |

**示例**：3 果断 + 2 犹豫 → 1.006。注意：全队果断对全队犹豫约值 3.6 分，比战术预算大。

### 完整示例（演示用，不是平衡证据）

双方默契 70、指挥 70（执行力 0.79），阶段评分已含心情压力（对抗 / 打野 / 中 / 发育 / 游走）：

| | 前期 | 中期 | 后期 |
|---|---|---|---|
| A | 66 / 70 / 66 / 64 / 66 | 60 / 62 / 60 / 58 / 62 | 56 / 56 / 57 / 56 / 57 |
| B | 58 / 60 / 58 / 56 / 58 | 62 / 62 / 63 / 60 / 62 | 70 / 68 / 70 / 72 / 68 |

- 阶段实力：A 66.296 / 61.236 / 56.322；B 57.849 / 62.909 / 69.583（中期已含默契 +2）
- 明星项：双方都为 0（领先都很平均，超出平均不到 4 分）
- Δ：E +8.447，M −1.673，L −13.260；f_E 0.9632，f_M 1，f_L 0.8142；Base −1.452

A 方单局胜率（无波动）：

| A \ B | B 入侵 | B 团战 | B 发育 |
|---|---|---|---|
| A 入侵 | 0.496 | 0.459 | 0.457 |
| A 团战 | 0.484 | 0.447 | 0.408 |
| A 发育 | 0.432 | 0.432 | 0.394 |

- A 前期领先、后期大幅落后；前期克后期把 B 的后期优势打了约 8 折（0.81），B 的团战小优势又让 A 的前期优势打了 96 折。整体 B 略强
- A 最好选入侵，B 最好选发育；选对和选错相差 4～10%

## Edge Cases

| 场景 | 处理 |
|---|---|
| 阵容缺分路 / 同队重复 / 双方重复 | 报错，不抽随机数，不改状态 |
| `bestOf` 偶数、≤ 0、> 9 | 报错，不抽随机数；BO1 合法，唯一一局为决胜局 |
| 配置：映射不合法、`p_floor` ∉ [0.05, 0.25]、`w_min` ∉ (0, 1]、任一 λ ∉ [0, 0.5]、`e0+e1+e2` ≠ 1（±0.001）、权重 ≤ 0、`2F + 2C` > 预算、单调性约束不满足、未知键、缺键、非数字 | 启动时校验失败，指出键名 |
| 某阶段双方全为 0、双方战术相同 | `Δ_k` = 0、`G₀` = 0、`p` = 0.5（战术不同时克制项不为 0） |
| 心情 0、压力 100、非主分路 | `v' ≥ 0.741v` |
| 任一 `Δ` 过零 | Base 连续，不跳 |
| 三个阶段同一方全领先 | 克制循环不触发 |
| 克制循环与战术同时作用 | 先算 Base（含 f_k），再加战术；战术对照从第 9 步重算 |
| `G` 很大，`p` 触顶 | 钳制；BO5 时爆冷约 3% |
| 默契 0、无指挥 | 执行力 0.3 |
| 多个不同绝活作用于同一挂钩点 | 相加 / 相乘再钳制 |
| `u` 恰为 `p` | A 方输（`u < p` 才赢） |
| 决胜局后 `v'` 超过 100 | 允许（最高 103），只用于本局 |
| 阵容里有请假选手 | 比赛不检查；由 team-state / 界面在锁定前挡住 |
| 同种子、同构建、同机器 | 完全一致；不保证跨平台 |

**已知的结构倾向**（交给平衡验证）
1. 偏向某一阶段的队，最优战术通常是专注该阶段（对阵匹配，有意为之）
2. 克制循环是温和的：风格偏向 9 分时约 52%*；风格的作用主要体现在"选择练什么去对付联赛"
3. 实力差距决定性强：差 5 分约 70%，差 10 分约 82%

## Tuning Knobs

| 旋钮 | 初值 | 安全范围 | 太高 | 太低 | 影响 |
|---|---|---|---|---|---|
| 阶段映射 | 见上 | 每格 ≥ 1 维 | — | 校验失败 | 训练对应哪个阶段 |
| `Lw` | 1–1.6 | 0.5–2.5（只看比例） | 该路独大 | 该路无关 | 明星位置 |
| `λ_E/λ_M/λ_L` | 0.15 / 0.5 / 0.15 | 0–0.5 | 偏科吃大亏 | 短板无代价 | 团战看短板、对线看明星 |
| `χ` 中期默契 | 1.0 | 0–2 | 默契决定团战 | 默契无用 | 默契价值 |
| `e0/e1/e2` | 0.3 / 0.4 / 0.3 | 和为 1 | — | — | 默契、指挥对战术的作用 |
| `B_k` | 1 / 1.1 / 1 | 0.5–2（只看比例） | 该阶段最重要 | 该阶段无关 | 版本环境 |
| `η` | 0.3 | 0–0.4 | 明星过强 | 明星无价值 | 明星价值 |
| `st0` / `cap` | 4 / 15 | 0–8 / 5–25 | 很少有明星 / 明星堆砌 | 假明星 / — | 明星判定 |
| `s` / `w_min` | 0.22 / 0.4 | 0–0.9 / 0.1–1 | 风格克制决定胜负 | 无克制 | 联赛风格的意义 |
| `a`, `F`, `C` | 0.1 / 1.0 / 0.5 | 受预算约束 | 战术比阵容重要 | 战术无意义 | 战术分量 |
| `m0`, `κ_s` | 0.95 / 0.025 | 0.85–1 / 0–0.1 | 状态无影响 | 状态压过养成（D1） | 状态对比赛的分量 |
| `g0`, `g1`, `c_cmd` | 2 / 6 / 0.3 | 0–5 / 0–10 / 0–0.5 | 结果接近随机 | 没有爆冷 | 爆冷、压力、指挥 |
| `k`, `p_floor` | 8 / 0.15 | 4–16 / 0.05–0.25 | 差距不重要 / 弱队机会大 | 差一点就稳赢 | 实力差距 |
| 决胜局系数 | 1.03 / 0.97 | 1–1.1 / 0.9–1 | — | — | 果断 / 犹豫 |
| 战报阈值 | 0.5 / 2 / 3 / 0.05 / 0.6 / 0.5 | — | — | — | 原因挑选、战术建议 |

**相互作用与失效**
- 战术预算 `2F + 2C ≤ 3`（校验）；`C/a` 决定对手战术何时影响你的选择
- `s` 与 `w_min`：|ΔS_X| ≥ (1 − w_min)/s × 10 时触底（0.22 / 0.4 → 27.3）；`s` = 0 时克制循环消失
- `λ` 与 `η` 方向相反（单调性约束校验）；`λ` = 0.5 时 Lw 仍有效
- `η` = 0 时明星类绝活无效；`C` = 0 时对手最近战术无价值；`g0 = g1 = 0` 时 `sigma_scale` 和 `c_cmd` 无效
- `k` 越小，同样 3 分战术越值钱
- 调整原则：先用原型确认是哪条结构在起作用，再动数字

**参赛与流程**
1. **GIVEN** 缺一个分路首发，**WHEN** 请求比赛，**THEN** 抛出 `InvalidLineup`（含分路 id），随机源调用 0 次，对象序列化前后相同
2. **GIVEN** 同一选手在同队两个分路，**THEN** 同第 1 条（含选手 id）
3. **GIVEN** 同一选手在双方首发，**THEN** 同第 1 条
4. **GIVEN** `bestOf` ∈ {−1, 0, 2, 4, 11}，**THEN** 报错且随机源 0 次；∈ {1, 3, 5, 7, 9} **THEN** 胜方恰得 `bestOf/2+1` 局
5. **GIVEN** 种子 S、夹具②，**WHEN** BO5 模拟，**THEN** 逐局结果与 golden 文件逐项相同（含新进程重跑）
6. **GIVEN** 脚本化随机源，**THEN** 第 1、2、3 个值依次为 A 波动、B 波动、掷骰；返回 u 时 ε = σ(2u − 1)
7. **GIVEN** 随机源总是 0，**WHEN** BO5，**THEN** A 3:0、抽 9 个；总是 0.99 → B 3:0、9 个；0 与 0.99 交替 → 3:2、15 个
8. **GIVEN** g0 = g1 = 0，**THEN** 每局仍抽 3 个
9. **GIVEN** 比赛完成，**THEN** 输入快照、选手、俱乐部、配置序列化前后相同
10. **GIVEN** 锁定快照后修改源对象，**THEN** 结果与不修改相同
11. **GIVEN** 非法阵容，**WHEN** Pending → Locked，**THEN** 拒绝，保持 Pending
12. **GIVEN** 种子 S 生成 1000 对阵容（r ~ U(30, 90)），双方各带随机挂钩表，**WHEN** 交换 A、B（挂钩随队），**THEN** 无波动 `p_A + p_B = 1`（±1e-9）

**配置**
13. **GIVEN** 每一种非法配置（映射 4 类、`p_floor` 0.049 / 0.251、`w_min` 0 / 1.2、`λ_M` 0.6、e 和 1.0011、`Lw` 0、`2F+2C` = 3.2、违反单调性约束、未知键、缺键、非数字），**THEN** 失败并含键名；`p_floor` 0.05、0.25 与 e 和 1.0009 通过
