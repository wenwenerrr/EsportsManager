## Summary

经济系统定义任何一支俱乐部（玩家和 AI 相同）的收支、选手的年薪和身价，以及"成功的代价"。代价主要落在**选手身上**（D4）：拿过冠军、练出绝活的选手市场价更高，年薪跟不上就不开心、要求重谈或想走；合同年限要谈，不能用长约躲涨薪；夺冠后一年还有媒体义务和额外压力（冠军疲劳）。联赛整体行情（工资指数）只是温和的背景，围绕联赛的常态收支比上下波动。

> **Quick reference** — Layer: `Core` · Priority: `MVP` · Key deps: `player-model, segment-actions, season-calendar`

## Overview

- **收入**：赞助、直播、商务分成、赛事奖金、事件收入、转会收入
- **支出**：工资（年薪 / 12 每赛段）、事件支出、转会支出
- **市场年薪**（F1）：看评分、人气、**估计**潜力，加荣誉和绝活加成，乘工资指数
- **心情里的"期望年薪" = 市场年薪**：被低估的明星每个赛段心情下降；转会期会要求重谈（F6）
- **合同年限要谈**：年轻选手长约加价，老将长约打折（F5）
- **工资指数**：按联赛收支比相对常态 R_ref 的偏离缓慢调整，0.8～1.3，负反馈（F3）
- **资金为负**：玩家和 AI 都先把替补卖给联赛自救；玩家卖到 5 人仍为负则破产，AI 则向联盟借款（以后从奖金和卖人收入里还）
- **去掉富者愈富**：拉赞助的成功率不再直接看成绩（D4）
- **冠军疲劳**：夺冠后 12 个赛段首发压力上升、商务邀约变多、每赛段要拿出行动点做媒体直播（成功的代价之二）
- **没有联赛补贴或分红**：中等俱乐部靠赞助、直播、商务和奖金略有盈余

## Player Fantasy

**钱是一种约束，成功会让队伍更贵。**

- 第一年：钱够用，但每笔投入都有取舍（拉赞助就少练一次）
- 夺冠后：明星的市场价涨了，他自己知道；不给他加薪，他会不开心、会想走，对手也会来挖
- 走商业路线：能赚很多钱，但行动点花在生意上，竞技会落后

## Detailed Design

### Core Rules

**设计决定记录**
- 2026-10-22：收入项沿用 §4.10～§4.12；荣誉、绝活进入年薪；所有俱乐部同一套公式
- 2026-10-23（用户 D4）：成功的代价以选手为主，工资指数只做温和背景；去掉"越强越容易拉到赞助"
- 2026-10-23（评审修正）：期望年薪用市场年薪；年薪 / 身价用估计潜力；合同年限定价；工资指数负反馈；玩家也能赛季中卖人自救；联盟补助改为借款；奖金入账时点；收入结构初值调整（待原型确认）
- 2026-10-27（全系统原型 fixG 回写，用户确认）：荣誉系数 h 0.7；重谈门槛 1.2；拒绝重谈 → 本转会期自动挂牌；工资指数以 R_ref 为中心、κ 0.25；冠军疲劳；收入初值（直播 7500、商务 ×2、赞助 11000 / 5 赛段、年度总决赛奖金 ×1.5）；不设联赛补贴

**每赛段结算**（顺序：行动 → 赛段结算 → 赛事 → 赛事奖金 → 资金检查）
1. 收入 = 直播 + 商务分成 + 赞助 + 事件收入
2. 支出 = Σ 年薪 / 12 + 事件支出
3. 资金 += 收入 − 支出
4. 本赛段结束的赛事按名次发奖金（§4.18），计入当年收入
5. 资金 < 0 → **自救**（F7）

**签约年薪**：任何签约、续约、挖角、补签、选拔的年薪 = F1 × 合同年限系数（F5）× R(0.1)。合同期内年薪不变。开局联赛选手的年薪再 × 0.85（league）。

**心情中的薪资满意度**（替换 §4.6 的期望年薪）
- 期望年薪 = 该选手当前市场年薪（F1，无随机项、年限系数 1）
- `满意度 = clamp(dz((年薪 − 期望) / 期望), −0.5, +0.2)`，`dz(x) = sign(x) × max(0, |x| − 0.1)`（±10% 死区）
- 满意度进入 §4.6 心情公式的 `m_salary` 项（系数 10 不变）

**重谈与转会请求**（每年转会期开始，F6）
- 合同剩余 ≥ 1 年、市场年薪 ≥ 1.2 × 现年薪的选手要求重谈
- 同意：年薪改为市场年薪（F1，无随机项、年限系数 1），合同年限不变
- 拒绝：该选手心情 −15，标记"想转会"（挖角目标优先级 ×2，见 transfer.md），下一年不再要求；**并在本转会期的出售步骤自动挂牌**（AI 与玩家相同；须满足 transfer.md 的挂牌限制，否则不挂）
**冠军疲劳**（成功的代价之二；玩家和 AI 相同；2026-10-27 用户决定）
- 触发：年度总决赛冠军 → 之后 12 个赛段，强度 `f` = 1；春 / 夏季赛冠军 → 之后 12 个赛段，`f` = 0.5；重叠时取较大的 `f`
- 每个赛段（强度 `f`）：
  - 每名首发压力额外 +6 × `f`（计入该赛段压力的原始值，再乘性格和随机系数，numbers.md §4.7）
  - 首发的商务邀约概率 × (1 + `f`)（不超过 1）
  - 先拿出 2 × `f` 个行动点做**媒体直播**（`f` = 1 → 2 点，0.5 → 1 点），由人气最高的首发承担（每人最多 2 点），按正常直播结算收入和人气
- 原型效果（fixG）：冠军队下一年首发平均压力约 59（普通约 40），训练点约少一半；全 AI 联赛卫冕率 14.5%

### States and Transitions

| 状态 | 进入 | 退出 | 行为 |
|---|---|---|---|
| 正常 | 资金 ≥ 0 | 资金 < 0 | — |
| 自救中 | 结算后资金 < 0 | 资金 ≥ 0 或名单 5 人 | 把评分最低的非首发以身价 × 0.6 卖给联赛（进自由选手池），逐个直到 ≥ 0 |
| 破产（玩家） | 自救后名单 5 人仍 < 0 | — | 游戏结束（任务 007） |
| 借款（AI） | 自救后名单 5 人仍 < 0 | 欠款还清 | 联盟借款补到 0；以后奖金和卖人收入的 50% 还款；欠款 > 年工资 25% 时，下个转会期必须挂牌年薪最高的首发 |

## Formulas

### F1 市场年薪

`salary = (S_min + (S_max − S_min) × WS(R_main, Pop, PotEst) / 100) × (1 + h × Honor/100 + s × n_spec) × trait_ask × WI`

| 变量 | 类型 | 范围 | 来源 | 说明 |
|---|---|---|---|---|
| S_min / S_max | int | 2 万 / 20 万 | 配置 | §4.4 |
| R_main | float | 0–100 | player-model | 主分路评分 |
| Pop | float | 0–100 | player-model | 人气 |
| PotEst | float | 0–100 | talent | **估计**潜力区间中心 |
| WS 权重 | — | 1 / 0.8 / 0.3 | 配置 | |
| Honor | float | 0–100 | F2 | |
| h | float | 0–0.8 | 配置 | 0.7（2026-10-27，原 0.4） |
| n_spec | int | 0–3 | growth | 绝活数 |
| s | float | 0–0.3 | 配置 | 0.15 |
| trait_ask | float | 0.92–1.05 | 性格 | 要价系数（续约时用续约系数） |
| WI | float | 0.8–1.3 | F3 | |

**输出范围**：约 1.5 万～59 万。
**示例**：评分 70、人气 60、估计潜力 75 → WS 66.90 → 基础 14.04 万；荣誉 80、1 个绝活 → ×1.71；WI 1.2 → **28.82 万**

### F2 荣誉分

`Honor = max(本年各赛事名次分)`

| 名次 | 冠军 | 亚军 | 3–4 | 5–8 / 未参加 |
|---|---|---|---|---|
| 春 / 夏季赛 | 70 | 50 | 30 | 0 |
| 年度总决赛 | 100 | 80 | 60 | 0 |

荣誉属于**选手**：按他本年效力俱乐部的名次计；转会时带走。新生成、选拔、自由选手为 0。

### F3 工资指数（负反馈）

`R = Σ_联赛 收入 / Σ_联赛 (工资 + 事件支出)`（上一年；收入不含转会、卖给联赛、借款、注资）
`WI_new = clamp(WI_old × (1 + κ × (R / R_ref − 1)), WI_min, WI_max)`（2026-10-27：以联赛常态收支比 R_ref 为中心）

| 变量 | 初值 | 范围 | 说明 |
|---|---|---|---|
| κ | 0.25 | 0–1 | rev 2 为 0.5 |
| R_ref | 0.942 | 0.85–1.1 | 联赛收支比的常态：全 AI 联赛、WI 固定 1.0 时各年 R 的中位数（原型 fixG 初值；任务 014 重测） |
| WI_min / WI_max | 0.8 / 1.3 | 0.6–1 / 1.1–1.6 | |

预热年 WI = 1；第一次正式转会期用预热年数据。R = R_ref 时 WI 不变。
**示例**：WI 1.0、R 1.06 → **1.031**；R 0.9 → 0.989；R = R_ref → 1.0

### F4 身价

`value = V_base × WS(R_main, PotEst, Youth) / 100 × (1 + v_s × n_spec)`

| 变量 | 初值 | 说明 |
|---|---|---|
| V_base | 50 万 | §4.5 |
| WS 权重 | 1 / 1 / 0.6 | 评分 / 估计潜力 / 年轻度 |
| Youth | clamp((32 − 年龄) × 8, 0, 100) | §4.5 |
| v_s | 0.25 | 每个绝活 |

**示例**：评分 75、估计潜力 80、21 岁（88）、1 个绝活 → WS (75 + 80 + 52.8)/2.6 = 79.92 → 39.96 万 × 1.25 = **49.95 万**

### F5 合同年限系数

| 年龄 | 1 年 | 2 年 | 3 年 |
|---|---|---|---|
| ≤ 23 | ×1.00 | ×1.06 | ×1.12 |
| 24–27 | ×1.00 | ×1.00 | ×1.00 |
| ≥ 28 | ×1.00 | ×0.96 | ×0.92 |

### F6 重谈

`合同剩余 ≥ 1 且 market ≥ r_ratio × salary`，`r_ratio` 1.2
**示例**：年薪 10 万的明星夺冠后市场 21.9 万 → 要求重谈

### F7 自救与借款

| 参数 | 初值 | 说明 |
|---|---|---|
| fire_sale | 0.6 | 卖给联赛的价格 = 身价 × 0.6 |
| repay | 0.5 | AI 奖金和卖人收入的还款比例 |
| debt_line | 0.25 | 欠款 > 年工资 × 0.25 → 下个转会期强制挂牌 |

### F8 收入项（沿用 §4.10～§4.12、§4.18 的公式；初值 2026-10-27 按全系统原型 fixG 确定）

| 项 | 公式 | 初值 |
|---|---|---|
| 直播 | `Σ (l_base + l_pop × 人气)`，同选手第二场 ×0.5 | `l_base` **7500**（rev 2 为 2800，v3.4 为 1500），`l_pop` 60 |
| 商务 | 邀约金额 `(a0 + a1 × 人气 + a2 × 颜值) × 性格 × R(0.2)`，俱乐部分成 70% | `a0 / a1 / a2` **10000 / 200 / 160**（v3.4 的 2 倍） |
| 赞助合同 | `c0 + c1 × 俱乐部人气`，**5** 赛段，最多 3 份 | `c0` **11000**（rev 2 为 6500），`c1` 100；每个空位每赛段可拉 1 次（玩家与 AI 相同） |
| 拉赞助成功率 | `clamp(z0 + z1 × 俱乐部人气/100 + U(−0.1, 0.1), 0.05, 0.8)` | `z0` 0.25，`z1` 0.5（去掉直接的成绩项） |
| 赛事奖金 | 按名次（numbers.md §4.18） | 年度总决赛 ×1.5：30 / 18 / 9 / 9 万；春夏季赛不变 |

调整原因：rev 2 评审算出收入结构偏赞助（61～63% vs 目标 40%）；2026-10-27 全系统原型 fixG：中位俱乐部收入 / 工资 ≈ 1.03（WI 1.0），结构约 赞助 47 / 直播 18 / 商务 18 / 奖金 15（EV3 通过）。**没有联赛补贴或分红**（用户决定）。

## Edge Cases

| 场景 | 处理 |
|---|---|
| 资金恰好 0 | 不触发自救 |
| 同一赛段内先负后正 | 只在结算和奖金之后判定 |
| 自救时没有非首发 | 直接破产（玩家）/ 借款（AI） |
| 预热年 / 第一次转会期 WI | 见 F3 |
| 联赛整体大赚 | WI 每年变化有限，封顶 1.3 |
| 合同未到期 | 年薪不变；满意度按市场年薪 |
| 同年多项名次 | 取最好一项 |
| 估计潜力区间宽 | 按中心计价，可能偏高偏低（赌博） |
| 冠军疲劳重叠（如春季赛冠军又拿年度冠军） | 取较大的强度 `f` |

## Tuning Knobs

| 旋钮 | 初值 | 安全范围 | 太高 | 太低 |
|---|---|---|---|---|
| `h` 荣誉 | 0.7 | 0–0.8 | 冠军队养不起人 | 夺冠没代价 |
| `s` 绝活 | 0.15 | 0–0.3 | 绝活选手太贵 | 绝活不值钱 |
| 满意度区间 / 死区 | [−0.5, 0.2] / 0.1 | — | 心情被薪资主导 | 薪资无影响 |
| `r_ratio` | 1.2 | 1.1–2 | 很少重谈 | 天天重谈 |
| 年限系数 | 见 F5 | ±0–0.1/年 | — | 年限无意义 |
| `κ`、R_ref、WI 范围 | 0.25 / 0.942 / 0.8–1.3 | 0–1 / 0.85–1.1 | 行情剧烈 | 行情不动 |
| `v_s`、身价权重 | 0.25；1/1/0.6 | — | — | — |
| `fire_sale` / `repay` / `debt_line` | 0.6 / 0.5 / 0.25 | — | — | — |
| 收入项 | 见 F8 | — | — | — |
| 冠军疲劳 | 压力 +6 / 商务 ×2 / 媒体 2 点；季赛冠军 ×0.5 | 0～2 倍 | 冠军必然掉队 | 卫冕太容易 |

相互作用：`h`、`s`、WI 相乘；满意度把它们变成心情压力，心情又影响训练效率（growth D1）。成功的代价由此落到养成上。

## Acceptance Criteria

> 单元测试强制（D6），`Assets/Tests/EditMode/Economy/`；随机项注入为 1；trait_ask 1。

1. **GIVEN** F1 示例，**THEN** 28.82 万（±0.01 万）；无荣誉、无绝活、WI 1 → 14.04 万
2. **GIVEN** 总决赛亚军 + 春季赛冠军，**THEN** 荣誉 80；转会选手保留自己的荣誉；新人 0
3. **GIVEN** WI 1.0、R_ref 0.942、κ 0.25，R 1.06 / 2.0 / 0.3 / 1.0 / 3.0 / 0.1 / 0.942，**THEN** 1.031 / 1.281 / 0.830 / 1.015 / 1.3 / 0.8 / 1.0
4. **GIVEN** F4 示例，**THEN** 49.95 万（±0.01 万）；改真实潜力不改结果
5. **GIVEN** 22 岁 / 30 岁签 3 年，**THEN** 年薪 ×1.12 / ×0.92
6. **GIVEN** 年薪 10 万，市场 10.5 / 13 / 25 万，**THEN** 满意度 0 / −0.131 / −0.5
7. **GIVEN** 市场 ≥ 1.2 × 年薪，**WHEN** 转会期开始，**THEN** 要求重谈；拒绝 → 心情 −15、"想转会"、次年不再要求，并在本转会期出售步骤自动挂牌（满足挂牌限制时）
8. **GIVEN** 资金 −10 万、替补 X 身价 8 万（评分低）、Y 身价 12 万，**THEN** 卖 X 得 4.8 万、卖 Y 得 7.2 万，资金 +2.0 万，X、Y 进自由选手池
9. **GIVEN** 自救到 5 人仍 < 0，**THEN** 玩家破产；AI 借款补到 0；之后奖金 50% 还款；欠款 > 年工资 25% → 下个转会期强制挂牌年薪最高的首发
10. **GIVEN** 玩家与 AI 相同输入，**THEN** 收支相同（借款是记录在 league.md 不对称清单里的例外）
