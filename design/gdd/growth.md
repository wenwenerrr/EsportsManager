## Summary

成长系统决定训练让选手怎么变强。每个训练点练一名选手的**一个阶段**（前期 / 团战 / 后期，或指挥），可以指定一个重点维度（在本阶段内多分涨幅）；心情越好练得越快，压力超过 50 后越来越练不动；每个维度最高只能到"潜力 + 10"。一直练同一阶段会形成专精，对应维度练到 76 且专精够深就解锁绝活（每个分路 × 阶段各一个）。它是 v4 里"深度放在养成"的主体：练什么、练谁、什么时候休息，决定一年后队伍的样子。

> **Quick reference** — Layer: `Core` · Priority: `MVP` · Key deps: `player-model, team-state, match`

## Overview

- **训练单位**：一个训练点 = 一名选手 × 一个阶段（或指挥）。该阶段所有维度一起涨；可选一个重点维度，在该阶段内多分涨幅（阶段平均涨幅不变）
- **各阶段成本相同**：不论阶段有几个维度、是否指定重点，阶段评分每点涨幅相同（消除"前期多为单维度所以最便宜"的问题）
- **状态管训练**（D1）：心情 0 → ×0.8，心情 100 → ×1.2；压力 ≤ 50 不影响，超过 50 每点 −2.3%，≥ 93.5 时练不动。压力高还更容易出坏事件（事件系统）。休息变成"为了练得更好"的投资
- **潜力是天花板**：每个维度最高 `min(100, 潜力 + 10)`；离天花板越近涨得越慢
- **专精**：每个训练点让该阶段专精靠近 1，其他阶段衰减；专精越深该阶段练得越快（最多 ×1.6）
- **绝活**：每个分路 × 阶段一个（15 个）+ 战术大脑；对应维度 ≥ 76 且该阶段专精 ≥ 0.55 时解锁；维度 < 73 或专精 < 0.30 时失去。潜力 < 66 的选手练不出维度类绝活
- **训练有小幅随机**（±15%）：看不出精确潜力
- 规则对玩家和 AI 完全相同
- **取代**：`numbers.md` §4.1 的"六维同涨 + 目标 ×1.5"和"按维度的余量"；rev 1 的"练一个维度 + 整体余量"。年龄系数、年龄衰退沿用 §4.1

## Player Fantasy

**我把他练成了某一种人，也把队伍练成了某一种队。**

- 高潜力新人在你手里长成"野区霸主"或"大后期"，是你一年投入的证明；低潜力选手再怎么练也成不了绝活明星——挖到好苗子才重要
- 练什么要看联赛：两支强队都练前期，你就练团战去克它们（match.md 克制循环）
- 状态管理有意义：压力大的队练不动，心情好的队练得快；休息不是为了某一场比赛，而是为了接下来练得更好
- 选手转会时绝活跟着走：卖掉一个绝活选手是真正的损失

## Detailed Design

### Core Rules

**设计决定记录**
- 2026-10-22：专精与绝活；第一版用 match.md 的挂钩点；二级绝活不做
- 2026-10-23（用户）：训练单位改为"一个阶段 + 可选重点维度"；每个维度上限 = 潜力 + 10；心情和压力都影响训练效率（D1）
- 2026-10-23（评审修正）：专精按训练点更新、解锁 / 失去区间 0.55 / 0.30；绝活无条件、价值接近；训练 ±15% 随机；训练按赛段开始时的数值计算（与任务 003 一致）
- 2026-10-27（全系统原型 fixG 回写，用户确认）：重点维度改为在阶段内重新分配（阶段平均涨幅不变）；专精按赛段点数一次更新（与点击顺序无关）；压力对训练改为阈值式（压力 > 50 才扣，`k_th` 2.3）；绝活门槛 76 / 73；绝活表改为每个分路 × 阶段一个（15 个）+ 战术大脑，取消跨分路绝活，数值按 match.md 示例校准到 ΔG 0.6～0.9

**训练（每个训练点）**
1. 分配一个训练点给一名选手，选目标：前期 / 团战 / 后期 / 指挥（主分路的阶段划分见 match.md 映射表）；可选一个属于该阶段的**重点维度**
2. 计算本点基础量 `b`（F1）
3. 目标阶段（共 `n_k` 个维度）每个维度 `d` 涨 `b × head_d × w_d`：不指定重点时 `w_d = 1`；指定重点维度时重点 `w = 1 + bonus × (n_k − 1)/n_k`、同阶段其他维度 `w = 1 − bonus/n_k`（阶段平均涨幅不变，单维度阶段指定重点没有额外效果）；其他维度（含指挥）涨 `b × head_d × s_other`
4. 目标是指挥时：指挥涨 `b × head_cmd`，其他维度涨 `b × head_d × s_other`
5. 维度钳制在 [0, `cap = min(100, 潜力 + 10)`]
6. **同一赛段多个训练点**都按赛段开始时的数值计算，最后合并生效（与任务 003 代码一致，结果与点击顺序无关）
7. 同一选手每赛段最多 2 个行动点（§4.16）

**专精**
- 每名选手存 `focus_E`、`focus_M`、`focus_L`（0～1）；初值由人才系统给出
- **每赛段末按点数一次更新**（结果与点击顺序无关）：`n` = 该选手本赛段训练点数（含指挥），`n_k` = 其中练阶段 k 的点数；`focus_k ← (1 − μ)^n × focus_k + (1 − (1 − μ)^n) × n_k / n`。只练一个阶段时等同于逐点 `focus_k ← (1 − μ) × focus_k + μ`、其他两项 `× (1 − μ)`；练指挥的点只让三项衰减
- 没被训练的选手专精不变

**绝活**
- 每个绝活绑定一个分路的一个维度（绝活表）。选手在**主分路**上检查
- 获得：该维度 ≥ `unlock_value`（76）且对应阶段专精 ≥ `unlock_focus`（0.55）；战术大脑（指挥）只看维度
- 失去：维度 < `lose_value`（73），或（非指挥绝活）专精 < `lose_focus`（0.30）
- 检查时机：每个赛段末尾（训练、专精更新之后），以及转会期年龄衰退之后
- 配置校验两条区间规则：`unlock_focus > μ + (1 − μ) × lose_focus`（一个训练点不能把失去的绝活重新激活）；`(1 − μ) × unlock_focus ≥ lose_focus`（一个不练的点不会让刚解锁的绝活立刻失去）
- 打非主分路时绝活不生效；获得 / 失去写进赛段结算

**挂钩表汇总**（交给比赛系统）
- 只统计**本场首发、打主分路**的选手的绝活；同一绝活多人拥有只算一次
- 不同绝活作用于同一挂钩点：按 match.md 相加 / 相乘（钳制由比赛系统做）

## Formulas

### F1 训练基础量

`b = T_base × I × age_f × trait_f × mood_t × stress_t × spec × noise`

| 变量 | 类型 | 范围 | 来源 | 说明 |
|---|---|---|---|---|
| T_base | float | 1–4 | 配置 | **2** |
| I | float | 1 | 配置 | 训练强度 |
| age_f | float | 0.3–1.2 | 配置 | §4.1 年龄档 |
| trait_f | float | 0.95–1.08 | 性格 | 训练系数 |
| mood_t | float | 0.8–1.2 | 计算 | `0.8 + 0.4 × 心情/100`（D1） |
| stress_t | float | 0–1.0 | 计算 | `max(0, 1 − k_th × max(0, 压力 − 50)/100)`，`k_th` 2.3：压力 ≤ 50 无影响，≥ 93.5 时为 0（2026-10-27；rev 2 为 `1 − 0.5 × 压力/100`） |
| spec | float | 1–1.6 | F3 | 专精系数 |
| noise | float | 0.85–1.15 | 随机 | 每个训练点一次 U(0.85, 1.15) |

**输出范围**：0 到约 5.7（压力 ≥ 93.5 时为 0）。
**示例**：21 岁、无性格、心情 60（1.04）、压力 30（1.0）、专精 0.5（1.3）、noise 1 → b = 2 × 1.04 × 1.0 × 1.3 = **2.704**；压力 70（0.54）→ **1.460**

### F2 维度涨幅与天花板

`head_d = clamp((cap − d) / span, 0, 1)`，`cap = min(100, 潜力 + cap_margin)`
`Δd = b × head_d × w_d`；`w_d`：目标阶段维度 1（指定重点时：重点 `1 + bonus × (n_k − 1)/n_k`，同阶段其他 `1 − bonus/n_k`）；其他维度 `s_other`

| 变量 | 初值 | 范围 | 说明 |
|---|---|---|---|
| cap_margin | 10 | 0–20 | 天花板高出潜力多少 |
| span | 25 | 10–40 | 距天花板多远开始变慢 |
| bonus | 0.5 | 0–1 | 重点维度在本阶段内多分的比例（阶段平均涨幅不变） |
| s_other | 0.1 | 0–0.3 | 其他维度顺带涨 |

**输出范围**：0 到 `1.33b`（3 维阶段的重点维度）；不超过 cap。
**示例**：潜力 65（cap 75）：维度 50 → head 1.0；70 → 0.2；75 → 0。b 2.298、打野练前期、重点 gold_per_min、所有维度 50：gold_per_min +3.064，kda、kill_contribution +1.915（前期平均仍 +2.298），其余 +0.230
**标定**（全系统原型，2026-10-27）：潜力 65 的 21 岁新人（起始约 0.775 × 潜力），心情 60、压力 30，只练一个阶段（打野前期、带重点）：每年 6 点 → 该阶段 +12.5、+6.5、+2.6；每年 12 点 → +19.4、+4.2。潜力 80：每年 6 点 → +14.0、+7.5。各分路 × 阶段第一年 +11.9～12.6

### F3 专精

每赛段末按点数一次：`focus_k ← (1 − μ)^n × focus_k + (1 − (1 − μ)^n) × n_k / n`（`n` = 本赛段训练点数含指挥，`n_k` = 练 k 的点数）；`μ` 0.163（两点 ≈ 0.3）。只练一个阶段时等同于每点 `focus_k ← (1 − μ) × focus_k + μ`、其他两项 `× (1 − μ)`
`spec = 1 + φ × focus_k`（目标为指挥时 `spec = 1`），`φ` 0.6

**示例**：0.2 / 0.2 / 0.2，2 点练前期 → focus_E = 1 − 0.8 × 0.837² = 0.440，其他 0.140；连续 3 段每段 2 点 → 0.440 → 0.607 → 0.725；改练团战每段 2 点 → focus_E 0.508 → 0.356 → 0.249

### F4 绝活判定

获得：`d ≥ 76` 且 `focus_k ≥ 0.55`（指挥只看 d）；失去：`d < 73` 或 `focus_k < 0.30`
**区间校验**：0.55 > 0.163 + 0.837 × 0.30 = 0.414 ✓；0.837 × 0.55 = 0.460 ≥ 0.30 ✓
**示例**：上例第 2 段末 focus_E 0.607，重点维度 ≥ 76 时解锁；改练团战后第 2 段末 0.356（保留），第 3 段末 0.249（失去）

### F5 事件修改训练

- `train_multiplier`：乘在该点的 `b` 上（影响所有维度）
- `train_add`：加到 `b` 上，再乘 `head_d`（不能突破天花板）

## Edge Cases

| 场景 | 处理 |
|---|---|
| 维度已到 cap | head 0，不再涨 |
| 潜力被事件降低，维度已超过新 cap | 维度不下降，只是不再涨 |
| 潜力 0 | cap 10，几乎不涨 |
| 压力 ≥ 93.5 | stress_t 0（不涨，维度也不下降） |
| 同一赛段多个点练不同阶段 | 维度和专精结果都与点击顺序无关 |
| 只练指挥 | 三项专精衰减；指挥绝活不看专精 |
| 选手不在主分路首发 | 绝活不进挂钩表；训练照常练主分路 |
| 维度在赛段中过 76 又被事件降到 75 | 只在赛段末检查 |
| 两名同绝活选手首发 | 只算一次 |
| 年龄衰退跌破 73 | 转会期检查时失去 |
| 训练预估 | 界面显示区间（±15%） |
| AI 选手 | 完全相同的规则 |

## Tuning Knobs

放 `player_config.json` 的 `training`、`specialty` 节；删除 `segment_config.json` 的旧 `training.target_bonus`。

| 旋钮 | 初值 | 安全范围 | 太高 | 太低 |
|---|---|---|---|---|
| `T_base` | 2 | 1–4 | 一两年练满，买人没意义 | 训练看不出效果 |
| `span` | 25 | 10–40 | 一直快、天花板突然 | 很早就练不动 |
| `cap_margin` | 10 | 0–20 | 潜力无意义 | 绝活太稀有 |
| `bonus` | 0.5 | 0–1 | 只练重点维度 | 冲绝活太慢 |
| `s_other` | 0.1 | 0–0.3 | 回到全面同涨 | 偏科 |
| `mood_t` 范围 | 0.8–1.2 | 0.6–1.4 | 心情决定一切 | 心情不影响训练 |
| `k_th`（阈值 50） | 2.3 | 1.2–3 | 必须频繁休息 | 压力无代价 |
| `φ`, `μ` | 0.6 / 0.163 | 0.2–1 / 0.1–0.3 | 专精压倒一切 / 换方向无代价 | 专精无意义 / 积累太慢 |
| 绝活门槛 | 76 / 73；0.55 / 0.30 | 受区间校验 | 太稀有 | 人人有 |
| 训练随机 | ±15% | 0–25% | 像抽奖 | 能反推潜力 |
| 绝活效果 | 见表（ΔG 0.6～0.9） | 受 match.md 钳制 | 绝活决定胜负 | 绝活不值得追 |

## 平衡验证

> 依赖任务 014 的机器人和全系统原型。

- **GV1**：21 岁、潜力 65、心情 60、压力 30、每年 6 点练一个阶段 → 该阶段第一年 +8～13（原型：各分路 × 阶段平均 12.2，范围 11.9～12.6；F2 标定里的 +12.5 是打野前期带重点维度的单例）
- **GV2 专精 vs 均衡**：≥ 120 种子 × 3 年；专精机器人和均衡机器人各自击败空闲机器人 ≥ 70%；两者互比各自更好的种子 ≥ 25%（排除平局）
- **GV3 绝活**（2026-10-27 重述）：专精机器人（前期 / 团战 / 后期 / 明星）和边际机器人第一年末玩家队各 1～3 个；均衡机器人只记录；联赛签约选手第 1 年 10%～25% 有绝活；≥ 50% 来自训练（原型 fixG：1.88 / 1.82 / 1.84 / 1.14 / 1.70，均衡 0.93；23%；99%。注意：第 3 年专精队约 3.2 个、第 5 年联赛约 34%，可能偏多，试玩后再看门槛）
- **GV4 状态管训练**：长期高压（≥ 70）的队一年成长比正常休息的队少 ≥ 30%
- **GV5 绝活价值**：每个绝活单独给 A 方（match.md 完整示例，A 入侵、B 发育，其余挂钩中性）时 ΔG 在 0.6～0.9（2026-10-27 在 s 0.25 下校准，见绝活表；任务 014 在 s 0.22 下复核）
