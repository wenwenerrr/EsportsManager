## Summary

人才系统决定新选手从哪里来、长什么样、潜力多少：开局联赛的选手、每年的青训和成熟自由选手、全国选拔的结果，以及谁退役。潜力是隐藏的，玩家只能看到估计区间；因为潜力决定每个维度的天花板（growth.md），挖到高潜力新人是真正的收获。全国选拔偏向"缺人的位置"，而不是"越强越容易出天才"。

> **Quick reference** — Layer: `Feature` · Priority: `MVP` · Key deps: `player-model, economy`

## Overview

- **生成**：先定潜力，维度按潜力比例随机（主分路 60%～95%，非主分路 35%～75%）
- **潜力**：天赋（5%）U(85, 95)；普通 clamp(N(μ, 10), 40, 84)。**取代** §4.13 的 U(40, 75)（`player_config` 的 `normal_potential_min/max` 和对应测试要一起改）
- **潜力隐藏**：估计区间，观察越久越准（§4.15）
- **人才供应**：每年 8 名青训 + 3 名成熟自由选手，潜力均值随联赛人气上升
- **全国选拔**：费用 5 万；天赋概率 5%～10%，看**本队该分路是否明显弱于联赛**（D4：去掉"越强越容易出天才"）
- **退役**：合同到期的老将和长期没人要的自由选手退役，选手总数保持稳定

## Player Fantasy

**挖到被低估的宝藏，或者花大价钱买到一个水货。**

- 估计区间宽的新人是赌博；潜力决定他能练到多高
- 缺人的位置更容易选拔到好苗子：弱队有翻身的入口

## Detailed Design

### Core Rules

**设计决定记录**
- 2026-10-22：沿用 §4.13、§4.15；人才供应随联赛人气；初始专精；生成时检查绝活
- 2026-10-23（用户 D4）：全国选拔不再"越强越容易出天才"
- 2026-10-23（评审修正）：普通潜力分布取代 §4.13；选拔费用提高；人才池减量并加退役；初始专精的并列规则；合同年限；名字表扩充
- 2026-10-27（全系统原型 fixG 回写，用户确认）：每年青训 8 名*（原型 fixG 用 7，8 为用户批准的微调，任务 014 复测）；选拔费用 5 万，天赋概率 5%～10%（need 按联赛中位数判断）；自由选手池上限在转会期开始和结束各执行一次；AC5 改为战术大脑

**选手生成**
1. 潜力：以概率 `p_talent` 为天赋 U(85, 95)；否则 `clamp(N(μ_pot, σ_pot), 40, 84)`
2. 主分路每个维度 = 潜力 × U(0.6, 0.95)；非主分路 = 潜力 × U(0.35, 0.75)（维度不超过 growth 的天花板 潜力 + 10）
3. 年龄、颜值、人气、心情、压力、性格按 `player_config.generation`
4. 初始专精：主分路三个阶段中，**阶段维度平均值**最高的阶段 0.4，其余 0.2；并列时按 E > M > L
5. 按成长系统规则检查绝活：维度类绝活需要专精 ≥ 0.55，而初始专精最高 0.4，所以生成时不会有；战术大脑只看指挥（≥ 76），生成时可能就有
6. 估计区间偏差 U(−b, +b) 在生成时定下，观察度 0
7. 年薪、身价由经济系统按估计潜力计算

**合同年限**：青训 3 年；成熟自由选手 2 年；选拔新人 3 年；开局选手 U{1, 3}

**开局联赛**（联赛系统调用）：8 支俱乐部各 6～7 人 + 约 25 名自由选手；`μ_pot` 用联赛人气 50 计算

**人才供应**（每年转会期开始）
- 生成 `n_youth`（8）名青训（17～19 岁）和 `n_free`（3）名成熟自由选手（21～27 岁）
- `μ_pot = y0 + y1 × 联赛人气 / 100`

**退役**（每年转会期开始，年龄 +1 之后）
- 合同到期且 ≥ 31 岁的签约选手：50% 退役；≥ 33 岁：必退
- 自由选手 ≥ 28 岁：每年 30% 退役；> 30 岁：必退
- 自由选手池超过 `pool_cap`（35）时，按评分从低到高移除（退役）；在转会期开始（年度新人加入后，当年青训豁免）和转会期结束（补签后，全部自由选手；本转会期流拍的联赛拍品不计入、也不会被移除，明年回到池中）各执行一次

**全国选拔**（转会期三选一之一，转会系统调用）
- 费用 `scout_cost`（5 万）；消耗本次转会期
- 生成 1 名 17～20 岁选手，分路由俱乐部指定；天赋概率按 F2（看该分路缺不缺人）
- 直接签入（3 年），年薪按经济 F1

**名字**：ID 表扩充到 ≥ 150 个；用完时加数字后缀

### States and Transitions

选手来源：生成 → 自由选手 / 签约 → 合同到期 → 续约 / 自由选手 / 退役。转会系统负责流转，本系统负责生成和退役判定。

## Formulas

### F1 人才供应潜力均值

`μ_pot = y0 + y1 × LeaguePop / 100`

| 变量 | 初值 | 范围 | 说明 |
|---|---|---|---|
| y0 | 50 | 40–60 | |
| y1 | 15 | 0–30 | 联赛人气影响 |
| LeaguePop | — | 0–100 | 8 队俱乐部人气平均（league） |
| σ_pot | 10 | 5–15 | |

**输出范围**：50–65。**示例**：联赛人气 40 → μ 56；钳制后实际均值 56.24。人气 30 vs 70：均值差 5.69

### F2 全国选拔天赋概率（看需求）

`p = clamp(t0 + t1 × need, t0, t_max)`

| 变量 | 初值 | 说明 |
|---|---|---|
| t0 | 0.05 | 基础 |
| t1 | 0.05 | 需求影响（2026-10-27，原 0.2） |
| need | 0 / 0.5 / 1 | 该分路没有主分路选手，或本队该分路最好的主分路选手评分 ≤ 联赛各队该分路最好者的中位数 − 5 → 1；否则只有 1 名主分路选手 → 0.5；其他 → 0 |
| t_max | 0.10* | 2026-10-27（原 0.25；原型 fixG 用 0.05，0.10 为保留"缺人位置更易出天才"的决定，任务 014 复测 TV2） |

**示例**：选拔明显弱于联赛的分路 → p = 0.10；只有 1 人的分路 → 0.075；其他 → 0.05。新人想要上场机会，所以缺人的队更容易吸引天才，但天赋概率始终很低。

### F3 潜力估计区间（沿用 §4.15）

`center = 潜力 + 偏差 × (1 − 观察度/100)`，`u = max(u_min, u0 × (1 − 观察度/100))`，区间 `[center − u, center + u]`；`u_min` 3，`u0` 20，偏差 ±10

## Edge Cases

| 场景 | 处理 |
|---|---|
| 正态抽样超出范围 | 钳制到 40～84 |
| 维度生成超过天花板 | 不会（0.95 × 潜力 < 潜力 + 10） |
| 名字用完 | 加数字后缀 |
| 联赛人气 0 | μ 50 |
| 选拔分路不合法 | 拒绝（只能是五个分路之一） |
| 退役后某俱乐部某分路无人 | 转会系统补签处理 |
| 自由选手池为空 | 紧急生成 1 名普通选手（潜力按当年 μ，23 岁，指定分路） |

## Acceptance Criteria

> 单元测试强制（D6），`Assets/Tests/EditMode/Talent/`。

1. **GIVEN** `p_talent` 0、联赛人气 40、种子 S，生成 2000 名，**THEN** 潜力均值 ∈ [55.2, 57.2]，最小 ≥ 40，最大 ≤ 84
2. **GIVEN** 联赛人气 30 vs 70，各 2000 名、`p_talent` 0，**THEN** 均值差 5.69 ± 0.5
3. **GIVEN** 注入潜力 80，**THEN** 主分路维度 ∈ [48, 76]，非主分路 ∈ [28, 60]
4. **GIVEN** 主分路阶段平均 E 最高 / M 最高 / L 最高 / E 与 M 并列，**THEN** 初始专精 0.4/0.2/0.2、0.2/0.4/0.2、0.2/0.2/0.4、0.4/0.2/0.2
5. **GIVEN** 构造的天赋选手（指挥 ≥ 76），**THEN** 生成后拥有战术大脑（不看专精）
6. **GIVEN** 选拔明显弱于联赛（≤ 联赛中位数 − 5）的分路 / 没有主分路选手的分路 / 只有 1 人且不弱的分路 / 已有 2 人且不弱的分路，**THEN** p = 0.10 / 0.10 / 0.075 / 0.05
7. **GIVEN** 合同到期的 33 岁签约选手，**THEN** 退役；31 岁 → 50%（种子固定可断言）；30 岁自由选手 → 年龄 31 并退役；29 → 30% 概率
8. **GIVEN** 自由选手池 40 人，**THEN** 移除评分最低的 5 人（转会期开始时当年青训豁免；结束时不豁免）
9. **GIVEN** 同一种子，**THEN** 两次生成完全相同
10. **GIVEN** 选拔，**THEN** 扣 5 万、17～20 岁、指定分路、合同 3 年
11. **GIVEN** 新人卡片（截图），**THEN** 潜力为区间

## 平衡验证

- **TV1**：≥ 120 种子 × 5 年，联赛选手总数保持 80～95；自由选手池 ≤ 35
- **TV2**：选拔新人的平均真实潜力比拍卖顶级青训低 ≥ 5，费用 / 拍卖成交价 ≤ 0.3
- **TV3**：联赛人气在正常游戏中的变化范围（记录，用于判断"联赛越火新人越好"是否有感知）
